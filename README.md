# 🛒 Grocery Store Management & Sales Analysis — SQL Project

## 📌 Project Overview

The **Grocery Store Management & Sales Analysis** project is a MySQL-based database project designed to manage grocery store operations and analyze customer purchases, product performance, sales trends, supplier contributions, and employee performance.

The project uses a relational database structure consisting of **7 interconnected tables** and SQL queries to extract meaningful business insights from grocery store transaction data.

---

## 🎯 Project Objectives

The main objectives of this project are to:

* Design a relational grocery store database using MySQL.
* Store and manage information about customers, products, suppliers, employees, categories, and orders.
* Establish relationships between different entities using Primary Keys and Foreign Keys.
* Analyze customer purchasing behavior.
* Identify top-performing products and categories.
* Analyze sales and order trends.
* Evaluate supplier contributions.
* Measure employee performance.
* Perform detailed analysis of order quantities and prices.
* Generate business insights using SQL queries.

   │

### Main Relationships

* One supplier can provide multiple products.
* One category can contain multiple products.
* One customer can place multiple orders.
* One employee can process multiple orders.
* One order can contain multiple order details.
* One product can appear in multiple order details.

## 📊 Business Analysis Performed

The project contains SQL queries covering several important business areas.

### 1. 👥 Customer Insights

The project analyzes:

* Number of unique customers who placed orders.
* Customers with the highest number of orders.
* Total spending by each customer.
* Top 5 customers based on purchase amount.

Example:

```sql
SELECT C.CUST_NAME,
       SUM(OD.TOTAL_PRICE) AS TOTAL_SPENT
FROM CUSTOMERS C
JOIN ORDERS O ON C.CUST_ID = O.CUST_ID
JOIN ORDER_DETAILS OD ON O.ORD_ID = OD.ORD_ID
GROUP BY C.CUST_NAME
ORDER BY TOTAL_SPENT DESC
LIMIT 5;
```

---

### 2. 📦 Product Performance

Product analysis includes:

* Number of products in each category.
* Average product price by category.
* Products with the highest sales volume.
* Revenue generated by each product.
* Product sales by category and supplier.

Example:

```sql
SELECT P.PROD_NAME,
       SUM(OD.QUANTITY) AS TOTAL_QTY
FROM ORDER_DETAILS OD
JOIN PRODUCTS P ON OD.PROD_ID = P.PROD_ID
GROUP BY P.PROD_NAME
ORDER BY TOTAL_QTY DESC;
```

---

### 3. 📈 Sales & Order Trends

The project analyzes:

* Total number of orders.
* Average order value.
* Dates with the highest number of orders.
* Monthly revenue trends.
* Weekday vs weekend order patterns.

Example:

```sql
SELECT ORDER_DATE,
       COUNT(*) AS TOTAL_ORDERS
FROM ORDERS
GROUP BY ORDER_DATE
ORDER BY TOTAL_ORDERS DESC;
```

---

### 4. 🚚 Supplier Contribution

Supplier analysis includes:

* Total number of suppliers.
* Supplier providing the highest number of products.
* Average product price by supplier.
* Supplier contribution to total sales revenue.

---

### 5. 👨‍💼 Employee Performance

The project evaluates:

* Number of employees who processed orders.
* Employee handling the highest number of orders.
* Total sales processed by each employee.
* Average order value handled by each employee.

Example:

```sql
SELECT EMP_NAME,
       COUNT(O.ORD_ID) AS TOTAL_ORDERS
FROM EMPLOYEES E
JOIN ORDERS O ON E.EMP_ID = O.EMP_ID
GROUP BY E.EMP_NAME
ORDER BY TOTAL_ORDERS DESC;
```

---

### 6. 🧾 Order Details Analysis

The project also performs detailed analysis of:

* Relationship between quantity ordered and revenue.
* Average quantity ordered per product.
* Minimum, maximum, and average selling price of products.
